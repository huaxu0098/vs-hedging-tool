## 实际主网与未验证项

真实主网对 metaAndAssetCtxs、l2Book、userAbstraction、clearinghouseState、activeAssetData、userFees、userFills、userFunding、spotClearinghouseState 九种查询返回 HTTP 200。l2Book WebSocket 收到双边各五档。使用公开查询用地址，测试当时返回 default。该次 funding 返回空数组；非空资金费、账户 WS 包装、重复及乱序事件使用合成样本核验。用户自己的主账户、子账户、资金费流水和到账记录尚未实测。

VS 当前采用用户粘贴或结构化 JSON 的确认快照。实际账户的固定及日内回撤、截止时区、权益触线定义、申领条件、账户身份、合约与结算币种仍需持有人提供。Hype 的目标 DEX、抵押币、Standard/统一/组合或逐仓/全仓、持仓与挂单占用、候选规模适用的杠杆和维持保证金档位/扣减、真实费率及有时间戳的汇率尚未按用户账户核实。真实候选的强平价及可执行仓位保留未验证。离线强平验证使用独立的 Standard 资金池模型；跳价压力与所有端点金额均为条件推演。

原工作台、历史提交与数据仍位于同一业务仓库；本版以 4180 专用路由和独立本地存储隔离。
