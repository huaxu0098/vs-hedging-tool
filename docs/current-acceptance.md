# 实时计算 1.1 验收记录

2026-11-19，上海时间。测试使用本机 4181 服务与隔离的真实 Chrome。账户录入测试使用明确给定的权益和持仓，报价、盘口、汇率、公开金库接口和成交记录均取自主网。浏览器网络断开由 Chrome 的离线开关触发。测试工作区独立于日常浏览器。

## 修改前的观察

实际访问原 4181 根路径时默认处于「离线模拟」，首屏展示标准单位、15.32% 模拟候选、5 单位和 −0.766 单位目标，主导航包含回放与考核模拟。原实时模式禁用权益编辑。原 liveBudget 同时检查钱包、账户匹配、本轮基准与行情，缺一项会清空输出。另一个 paper 查询路径启动固定出金副本并创建模拟成交。

本次替换 `hedge.html` 与 `src/hedge/entry.js` 的生产入口。`src/hedge/current.js` 从当前快照派生估值与计算输入；`src/hedge/math.js` 和 `solver.js` 按既有公式计算资金区间、固定现仓或联合仓位，并算出差额。`scripts/current-market.js`、`scripts/serve.js` 与 `src/hedge/current-account.js` 处理公开行情和只读账户。生产服务不会启动旧 paper 进程或创建虚拟流水。
